# 의료기록 비식별화 실행·복구 안내

이 문서는 진단서·처방전·복약안내서·의무기록처럼 개인정보가 포함될 수 있는 첨부파일을 안전하게 시험하고, 앱이나 코드에 문제가 생겼을 때 복구하는 방법을 정리합니다.

## 데이터가 머무는 위치

| 단계 | 저장되는 데이터 | 위치·보존 |
|---|---|---|
| 웹 첨부 직후 | 원본 이미지 또는 PDF | 현재 브라우저 메모리만 사용, 검토 완료·취소 시 폐기 |
| 비식별화 확인 후 | 검은 상자가 합성된 JPEG 사본 | 판독 입력과 브라우저 IndexedDB 초안에만 사용 |
| 앱 재시작 복구 | 확인 완료 비식별화 사본 | 같은 기기에서 최대 30분 자동 복원 |
| 로컬 Python 도구 | 원본 PNG와 별도 출력 PNG | 사용자가 지정한 로컬 경로만 사용 |
| GitHub | 소스 코드·문서·테스트 | 실제 의료기록과 생성 사본은 커밋 금지 |

웹 앱에서 검은 상자를 합성한 사본은 픽셀을 덮어쓰므로 그 파일만으로 개인정보를 복원할 수 없습니다. 원본이 업무상 필요하면 기관 정책이 허용하는 암호화 저장소에 별도로 보관하고, 비식별화 출력과 섞지 마세요.

## 웹에서 실행

1. `npm install` 후 `npm run serve`를 실행합니다.
2. `http://127.0.0.1:8765`에서 의료기록의 `촬영` 또는 `갤러리`를 선택합니다.
3. 자동 가림 결과에서 누락 영역을 드래그해 추가하고 오탐 상자는 삭제합니다.
4. 개인정보가 보이지 않는지 직접 확인한 뒤 확인란을 선택합니다.
5. `사본 저장`으로 결과만 먼저 내려받아 점검하거나 `비식별화 사본 사용`으로 판독에 등록합니다.

새로고침이나 모바일 카메라 전환으로 앱이 재시작되면, 확인 완료 사본만 30분 안에 자동 복원됩니다. 원본이나 확인 전 페이지는 복원 대상이 아닙니다. `초기화`를 누르면 이 초안도 삭제됩니다.

## Python 도구로 오프라인 실행

첨부 자료의 EasyOCR·Presidio 방식은 [`tools/pii-redactor/`](../tools/pii-redactor/)에 독립 도구로 보존합니다. 이 도구는 배포 웹 앱이나 외부 API와 연결되지 않으며 PNG 파일만 처리합니다.

```powershell
cd tools\pii-redactor
.\setup.ps1
.\run.ps1 -InputPath private\input.png -OutputPath output\input_redacted.png
```

`private/`와 `output/`은 `.gitignore` 대상입니다. 명령 실행 전후에 `git status --short`로 실제 문서가 추적되지 않는지 확인하세요.

## 복구 방법

### 앱 초안 복구

- 같은 브라우저·같은 기기에서 30분 안에 앱을 다시 열면 확인 완료 사본이 자동 복원됩니다.
- 30분이 지났거나 `초기화`를 누른 경우에는 원본을 다시 등록하고 검토해야 합니다.
- 개인정보 보호를 위해 원본 자동 복구 기능은 제공하지 않습니다.

### 로컬 파일 복구

- Python 도구는 입력 원본을 수정하지 않고 새 출력 파일을 만듭니다.
- 출력에서 가림을 되돌리는 기능은 제공하지 않습니다. 필요하면 승인된 원본으로 다시 작업합니다.
- `private/` 원본과 `output/` 사본의 접근권한·보존기간은 기관 정책에 따릅니다.

### 코드 복구

현재 변경을 버리지 않고 이전 상태를 확인하려면 새 폴더에 저장소를 다시 복제하는 방법이 가장 안전합니다.

```powershell
git clone https://github.com/growdaily860-cell/KCSI-MED-main.git KCSI-MED-recovery
cd KCSI-MED-recovery
git log --oneline --decorate -10
```

이미 반영된 특정 커밋을 취소해야 하면 이력을 삭제하는 `reset --hard` 대신 새 취소 커밋을 만드는 `git revert <commit>`을 사용하세요. 실행 전 `git status -sb`로 사용자 변경이 없는지 확인합니다.

## 배포 전 확인

```powershell
npm test
git status --short
```

- 실제 진단서·처방전·예시 원본이 Git 추적 목록에 없어야 합니다.
- 검토 확인 전에는 `사본 저장`과 `비식별화 사본 사용`이 비활성화되어야 합니다.
- 재시작 복원 데이터에는 `redacted === true`인 의료기록만 포함되어야 합니다.
- 외부 AI로 보내기 전 화면에서 남은 개인정보가 없는지 사람이 최종 확인해야 합니다.
